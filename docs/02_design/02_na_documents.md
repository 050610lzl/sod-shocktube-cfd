# 不适用的软件文档说明

本文件说明用户需求文档清单中各项文档对本项目的适用性。本项目为一维Sod激波管CFD科学计算软件（CLI工具），与传统的Web应用/企业信息系统在架构上有本质差异。

## 不适用的文档及原因

### 二、设计类

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 数据库设计文档（表结构、字段、索引、ER图） | **不适用** | 本项目不使用任何数据库。所有数据以NumPy数组（.npy格式）和CSV文件存储，无需数据库设计。 |
| 前端/页面设计文档 | **不适用** | 本项目为CLI命令行工具，无图形界面/Web前端。可视化通过Matplotlib自动生成PNG图片。 |
| 安全设计方案 | **简化适用** | 本项目为本地单用户科学计算软件，不涉及网络通信、用户认证、数据加密。安全风险极低。唯一安全考量：输入配置文件的合法性校验。 |

### 四、测试类

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 安全测试报告 | **不适用** | 无网络接口、无用户数据、无认证机制。安全测试维度不适用于本软件。 |

### 五、部署运维类

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 服务器环境配置文档 | **简化适用** | 本项目为单机运行，无需服务器配置。相关内容已整合到《软件部署手册》中。 |
| 数据库初始化脚本 | **不适用** | 无数据库。 |

### 六、使用培训类

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 管理员操作手册 | **合并** | 本项目无管理员/普通用户角色区分。所有操作统一在《用户使用手册》中说明。 |
| 角色权限使用说明 | **不适用** | 单用户软件，无角色权限系统。 |
| 业务操作培训文档 | **合并** | CLI命令行操作简单直观，培训内容已整合到《用户使用手册》中。 |

### 七、交付 & 验收类

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 售后服务协议 | **不适用** | 本项目为MIT开源软件，按"AS IS"原则提供，无商业售后服务义务。用户可通过GitHub Issues获取社区支持。 |

### 八、合规 & 附加文档

| 文档 | 适用性 | 原因 |
|------|--------|------|
| 隐私政策 | **不适用** | 本软件不收集、不存储、不传输任何用户个人数据。 |
| 用户协议 | **简化适用** | MIT LICENSE文件已包含使用许可和免责声明，无需单独的EULA。 |
| 数据安全说明 | **不适用** | 无用户数据、无网络传输、无第三方数据共享。 |

## 替代方案

对于标记为"不适用"的文档需求，本项目提供以下替代或整合方案：

| 原需求 | 替代方案 |
|--------|----------|
| 数据库设计文档 | 数据格式说明（已包含在《接口设计文档》§5 文件I/O接口） |
| 前端/页面设计文档 | CLI接口说明（已包含在《接口设计文档》§2 CLI接口） |
| 安全设计方案 | 输入校验说明（已包含在《接口设计文档》§7 错误处理） |
| 安全测试报告 | Bug清单中的安全相关条目（BUG-001/002/004） |
| 服务器环境配置 | 部署手册中的系统要求和安装步骤 |
| 角色权限 | 无需要（单用户CLI工具） |
| 售后服务协议 | MIT LICENSE + GitHub Issues社区支持 |
| 隐私政策/用户协议 | MIT LICENSE + 源代码授权说明 |
