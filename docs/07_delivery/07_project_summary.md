## 1. 项目概述

### 1.1 项目背景

Sod 激波管问题是计算流体力学（CFD）领域最经典的验证基准问题，由 Gary A. Sod 于 1978 年提出 [1]。该问题模拟一根被隔膜分隔为高压区和低压区的管道，隔膜破裂后产生左稀疏波、接触间断和右激波三种典型的流体动力学间断结构。由于该问题存在解析精确解（可通过 Riemann 求解器获得），使其成为检验数值格式对间断捕捉能力的理想测试案例。

### 1.2 项目目标

本项目旨在基于有限差分法（FDM）离散一维可压缩 Euler 方程，实现多种经典数值格式，与 Riemann 解析精确解进行定量对比验证。

核心目标：
1. 实现 9 种经典 FDM 格式，涵盖一阶到二阶、中心到迎风、经典到现代的格式谱系
2. 实现 Riemann 精确解求解器（基于 Toro 2009），作为对比基准
3. 建立完整的误差分析框架（L1、L2、Linf 范数）
4. 构建工程化、可复用的 CFD 项目框架

### 1.3 项目范围

| 维度 | 范围描述 |
|------|----------|
| 物理问题 | 一维可压缩无黏 Euler 方程（Sod 激波管标准工况） |

## 2. 技术方案总结

### 2.1 有限差分法（FDM）实施

采用显式有限差分法离散一维 Euler 方程守恒形式：

```
dU/dt + dF/dx = 0
```

其中 U = [rho, rho*u, E]^T，F = [rho*u, rho*u^2+p, u*(E+p)]^T。

**时间推进**：显式一阶 Euler 方法，时间步长由 CFL 条件约束。
**空间离散**：各格式通过不同的数值通量或差分模板离散空间导数。

### 2.2 9 种格式清单

| 序号 | 格式 | 精度 | 类型 | 关键文献 |
|:----:|------|:----:|------|----------|
| 1 | Lax-Friedrichs | 一阶 | 中心耗散 | Lax (1954) |
| 2 | Lax-Wendroff | 二阶 | 中心色散 | Lax & Wendroff (1960) |
| 3 | MacCormack | 二阶 | 预估校正 | MacCormack (1969) |
| 4 | 一阶迎风 | 一阶 | Steger-Warming 分裂 | Steger & Warming (1981) |
| 5 | Rusanov | 一阶 | 局部 Lax-Friedrichs | Rusanov (1961) |
| 6 | Godunov | 一阶 | 精确 Riemann 求解 | Godunov (1959) |
| 7 | Roe | 一阶 | 近似 Riemann 求解 | Roe (1981) |
| 8 | HLLC | 一阶 | 恢复接触间断 | Toro et al. (1994) |
| 9 | TVD-Minmod | 二阶 | 通量限制 | Harten (1983) |

### 2.3 Riemann 精确解

基于 Toro (2009) [2] 第 4 章的精确 Riemann 求解器算法：
- 利用 Newton-Raphson 或 Brent 方法求解压力方程
- 利用 Riemann 不变量和 Rankine-Hugoniot 关系确定波后状态
- 根据 x/t 比值确定采样点所在区域

### 2.4 误差分析框架

对每种格式的密度(rho)、速度(u)、压力(p)计算三种误差范数：

- **L1 误差**：平均绝对误差 = sum(|num - exact|) / N
- **L2 误差**：均方根误差 = sqrt(sum((num - exact)^2) / N)
- **Linf 误差**：最大绝对误差 = max(|num - exact|)

## 5. 经验教训

### 5.1 成功经验

1. **模块化设计**：将网格生成、流场初始化、格式实现、边界处理、时间推进、精确解求解分离为独立模块，显著提高了代码可维护性和可测试性。

2. **文献驱动的开发**：每个数值格式的实现严格参照原始文献（Roe 1981, Toro 1994, Harten 1983 等），确保了数值方法的正确性。

3. **CI/CD 集成**：通过 GitHub Actions 实现了多 Python 版本的自动化测试、代码风格检查和集成测试，在开发早期就发现了多个 bug。

4. **时间戳归档机制**：强制按时间戳归档仿真结果，避免了重复运行时覆盖历史数据的问题，极大方便了收敛性研究工作。

5. **YAML/JSON 配置化**：将所有仿真参数外置到配置文件（支持 YAML 和 JSON 双格式，`load_any_config` 自动检测），配合命令行参数覆盖机制，实现了灵活的仿真控制。

### 5.2 遇到的问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Lax-Wendroff/MacCormack 在粗网格下振荡严重 | 二阶中心格式固有的 Gibbs 现象 | 增加 TVD 格式作为对比，文档中说明振荡行为 |
| Godunov 格式运行缓慢 | 每界面需迭代求解 Riemann 问题 | 优化 Brent 求根算法，接受该格式的性能特征 |
| NumPy 2.0 breaking changes | NumPy 2.0 移除了多项 API | 锁定 numpy<2.0.0 版本约束 |
| CI 中 Python 路径问题 | 测试导入 src 包失败 | 使用 pip install -e . 安装项目 |
| 接触间断分辨率低 | 一阶格式的固有缺陷 | 引入 HLLC 格式专门恢复接触间断 |

### 5.3 待改进之处

1. **Godunov 格式性能**：精确 Riemann 求解器的计算效率有待提升（可考虑查表法加速）
2. **高阶时间推进**：当前仅实现一阶 Euler 时间推进，后续可引入 RK2/RK3
3. **自适应网格**：对于激波区域自适应加密可以显著提升分辨率/计算量比
4. **三维扩展**：当前仅支持一维 Euler 方程

## 7. 结论

本项目成功实现了一维 Sod 激波管 CFD 求解器，覆盖了 9 种经典有限差分格式，并与 Riemann 精确解进行了系统的定量对比验证。项目遵循了工程化的软件开发流程，包括模块化设计、单元测试、CI/CD 集成、版本管理和完整文档编写。

通过本项目的实施，获得了以下核心结论：

1. TVD-Minmod 格式在精度、稳定性和无振荡性方面取得最佳平衡
2. HLLC 格式对接触间断的分辨率优于其他一阶格式
3. 一阶格式的数值耗散在粗网格下显著降低了精度
4. 二阶格式在间断处的振荡需要限制器机制来抑制
5. 网格收敛性研究表明所有格式均达到了理论精度阶
