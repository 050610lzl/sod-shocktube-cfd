## 3. 软件技术特点

### 3.1 技术领域

本软件属于**计算流体力学（CFD）**领域，具体涉及：

- 一维可压缩无黏 Euler 方程的数值求解
- 有限差分法（Finite Difference Method, FDM）的空间离散
- Riemann 问题的精确解与近似解求解
- 双曲型守恒律方程的高分辨率格式

### 3.2 创新性技术特点

#### 3.2.1 多格式集成框架

本软件在一个统一的框架内集成了 **9 种**经典的有限差分法数值格式，涵盖：

- **中心差分型**: Lax-Friedrichs（一阶）、Lax-Wendroff（二阶）、MacCormack（二阶预估校正）
- **迎风型**: 一阶迎风（Steger-Warming 通量分裂）、Rusanov（局部 Lax-Friedrichs）
- **Riemann 求解器型**: Godunov（精确 Riemann 求解器）、Roe（近似 Riemann 求解器）、HLLC（Harten-Lax-van Leer Contact，恢复接触间断）
- **高阶限制器型**: TVD-Minmod（通量限制器，保单调二阶精度）

这种集成化的对比框架在国内 CFD 教学软件中具有独特价值。

#### 3.2.2 Riemann 精确解求解器

基于 Toro (2009) 的精确 Riemann 求解器算法，实现了迭代式压力方程求解（Newton-Raphson / Brent 方法），结合 Riemann 不变量和 Rankine-Hugoniot 关系，为数值解提供了可靠的对比基准。

#### 3.2.3 定量误差分析体系

实现了三种误差范数（L1、L2、Linf）的自动化计算，针对密度、速度、压力三个物理量进行全方位精度评估，支持网格收敛性研究。

#### 3.2.4 时间戳归档机制

每次仿真自动生成 YYYYMMDD_HHMMSS 格式的时间戳，将数据文件和可视化结果分别归档，避免重复运行时的数据覆盖问题，适用于大规模参数扫描研究。

#### 3.2.5 工程化软件实践

- PEP 517/518/621 标准的 Python 包管理
- YAML 配置文件驱动的参数化仿真
- GitHub Actions 多 Python 版本 CI/CD 自动测试
- 语义化版本管理（SemVer 2.0.0）
- 34 项单元测试 + 9 种格式集成测试

## 5. 创新点说明

### 5.1 主要创新点

1. **一维 Sod 激波管 CFD 求解器**：基于有限差分法（FDM）对一维可压缩 Euler 守恒方程进行离散求解，实现了对 Sod 激波管问题中三种典型波系结构（左稀疏波、接触间断、右激波）的数值模拟。

2. **9 种经典 FDM 格式集成化对比平台**：在一个统一的求解器框架内集成了从一阶到二阶、从中心差分到迎风型、从经典到现代的 9 种有限差分格式，提供了系统的格式精度与稳定性对比能力。

3. **基于 Toro (2009) 的 Riemann 精确解求解算法**：实现了基于迭代求根算法的精确 Riemann 求解器，能够为数值解提供严格的解析基准，具有重要的学术验证价值。

4. **L1/L2/Linf 定量误差分析框架**：在密度、速度、压力三个物理量上实现了三种误差范数的自动化计算，为数值格式的精度评估提供了标准化的量化手段。

5. **工程化 CFD 软件框架**：采用模块化设计、YAML 配置驱动、CI/CD 自动化测试、语义化版本管理、时间戳结果归档等现代化软件工程实践，构建了可复用的 CFD 软件开发框架。

### 5.2 技术创新性说明

本软件在 CFD 教学和研究领域填补了小型化、集成化、易用化的多格式对比求解器的空白。与大型商业 CFD 软件或复杂开源项目相比，本软件具有部署简单、上手快速、格式对比直观的特点，特别适合用于：

- CFD 课程教学中的数值格式对比演示
- 新数值方法原型的快速验证
- 双曲型守恒律数值方法的基准测试
