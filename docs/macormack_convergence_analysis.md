**观测到的收敛阶远低于理论值2阶**（约 0.1~0.4 之间），且随着网格加密进一步下降。

## 3. 原因分析

### 3.1 激波/接触间断处的非光滑性（核心原因）

Sod激波管问题包含三个关键波结构：
1. **稀疏波**（smooth rarefaction fan）-- 光滑解
2. **接触间断**（contact discontinuity）-- 密度跳跃，u、p连续
3. **激波**（shock wave）-- 所有物理量跳跃

MacCormack格式是**二阶中心型格式**（预估步前差分 + 校正步后差分 + 平均）。对于光滑区域，它确实能达到二阶精度。但对于包含**间断**的问题：

- **Godunov定理** (1954): 线性单调格式最高只能达到一阶精度。
- MacCormack格式是非线性的（通过预估-校正过程），但在间断附近仍会产生**非物理振荡**（Gibbs现象）。
- 间断处的误差 **不随网格加密而衰减**，误差主要来自间断附近的有限宽度区域。

### 3.2 L1误差的渐近行为

对于含间断的问题，数值格式的L1误差理论分析表明 [LeVeque, 2002]:

$$\|e\|_{L^1} = O(\Delta x^{1/2}) \text{ 至 } O(\Delta x^{1})$$

这是因为：
- 间断附近的误差贡献约为 O(1) * O(dx) = O(dx)（间断宽度约几个网格单元）
- 但间断位置的数值扩散导致间断"模糊"，模糊区域宽度与 dx 有关
- 光滑区域的误差为 O(dx^2)，但在整个域上积分后，间断区域的贡献占主导

### 3.3 为何收敛阶"趋近于0"而非固定低阶

观测到的收敛阶从0.39逐步下降到0.08，这是因为：

1. **误差渐近平台**: 当网格足够细时，间断附近的误差趋于常数平台。
   - 间断处始终存在约2-3个网格单元的过渡区
   - 即使N=800，间断区仍有约2-3个单元，贡献固定量级的误差

2. **光滑区域误差 vs 间断区域误差**:
   - 光滑区域误差 ~ O(dx^2)，随网格加密快速衰减
   - 间断区域误差 ~ O(dx)，衰减缓慢
   - 当网格变细时，光滑区域误差已很小，总误差由间断区域主导

3. **数值振荡的影响**: MacCormack格式在间断附近产生振荡（overshoot/undershoot），这些振荡幅度随网格加密缓慢减小。

### 3.4 与其他格式的对比

| 格式             | 理论阶 | 实测L1_rho收敛阶 | 备注                       |
|------------------|--------|------------------|---------------------------|
| Lax-Friedrichs   | 1      | ~0.55            | 一阶耗散格式，单调性好      |
| Lax-Wendroff     | 2      | ~0.77            | 二阶但有色散振荡            |
| MacCormack       | 2      | ~0.18 (平均)     | 二阶但振荡严重，收敛最差    |
| TVD (Minmod)     | 2      | ~0.35 (平均)     | TVD限制器抑制振荡           |

### 3.5 实现层面的额外因素

1. **边界条件处理**: 零梯度外推在激波穿过边界时引入额外误差。
2. **预估-校正的不对称性**: 本实现的预估步仅用前差分（i+1 - i方向），导致在特定方向上的波传播存在非对称数值粘性。
3. **压力计算**: 通过守恒变量间接计算压力 (p = (gamma-1)*(E - 0.5*rho*u^2))，在间断附近可能出现小的负压力（已被clamp保护）。

## 4. 结论与建议

### 结论

MacCormack格式在Sod激波管问题中收敛阶偏低（~0.18）是**理论预期行为**，而非实现缺陷。根本原因是：

1. **问题的非光滑性**：Sod问题包含激波和接触间断，违背了Taylor展开光滑性假设
2. **Godunov限制**：含间断问题的L1误差理论上限为 O(dx^(1/2)) ~ O(dx^1)
3. **振荡主导误差**：MacCormack的色散误差在间断处产生振荡，抵消了二阶精度优势

### 改进建议

1. **添加TVD限制器**: 将MacCormack与限制器结合（如MacCormack-TVD），在间断处降阶到一阶、光滑区恢复二阶
2. **人工粘性**: 在间断区域添加局部人工耗散
3. **改用Riemann求解器**: 如Roe、HLLC格式天然处理间断
4. **误差度量改进**: 使用L1误差在间断问题中不能准确反映格式精度，应分别统计光滑区域和间断区域的误差
